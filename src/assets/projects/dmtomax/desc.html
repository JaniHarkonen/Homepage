DMtoMax is a simple program that maps DeepMotion-motion capture data from one format to another by replacing joint names in the DeepMotion-file to user-specified ones. By default, DMtoMax maps DeepMotion joints into 3ds Max joints, however, the app allows the user to configure and customize each mapping. Once mappings have been specified, the user can import files and convert them via the control panel. Converted files will be highlighted in green while ones that failed to convert are highlighted in red.

DMtoMax was built using React, JavaScript, CSS and HTML and powered by Electron.
