DumpEm Suite 2 is a collection of tools that allows me to structure and carry out my investment process. It is the second iteration of the DumpEm Suite -platform. In addition to having new modules and tools, DumpEm Suite 2 features FlexibleSplits technology, which allows the user to customize the UI layout to fit their needs. The app also has a custom markdown version with embeddable widgets, such as the TradingView-chart widget.

Companies are imported into a DumpEm Suite 2 workspace either manually or via a scraper written in my ScrapeScript programming language. The companies can then be filtered out in steps until the final set of candidates are left. The app allows the user to take notes using the custom markdown version as well as gather investment materials in one place. Additionally, DumpEm Suite 2 has a changeable theme as well as hotkeys that can be used for navigation.

DumpEm Suite 2 was designed to be highly customizable, flexible and extendable. It was built using React, TypeScript, CSS, HTML and SQLite and powered by Electron.
